# SDBD Pulse Detector

Детектирование положительных и отрицательных импульсов тока в осциллограмме тока поверхностного барьерного разряда.

## Установка

Нужен Python 3.13:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Данные

Исходные записи — файлы `.npz`. В каждом файле три массива одинаковой длины:

- `t` — время, нс;
- `i` — ток;
- `v` — напряжение на разрядном промежутке.

Файлы группируются по напряжению источника питания. Имя папки — это напряжение в вольтах, например `2200`.

В репозитории лежит один размеченный и один неразмеченный пример на 2200 В:

| Путь | Назначение |
|---|---|
| `example_labeled_data/2200/` | Осциллограмма для обучения |
| `selections/2200/time_events.txt` | Ручная разметка импульсов к этой осциллограмме: каждая строка — `начало конец` |
| `example_unlabeled_data/2200/` | Осциллограмма без разметки, чтобы проверить уже обученную модель |

Импульсы длятся наносекунды, но в разметке и внутри конвейера время задано не в наносекундах. Каждый отсчёт осциллограммы (0,5 нс) отображается в 0,5 с условного времени, отсчитываемого от опорной даты `2024-01-01`. Так библиотека `eventdetector` получает обычные метки `datetime`, а границы событий удобно читать глазами: в `time_events.txt` каждая строка — пара ISO-меток `начало конец` уже в этом растянутом времени.

Чтобы обучать на своих записях, положите `.npz` в `example_labeled_data/<напряжение>/`, а разметку — в `selections/<напряжение>/time_events.txt` в том же формате.

## Обучение

```bash
python train_model_concat.py
```

Настройки — константы в начале `train_model_concat.py` (`TARGET_VOLTAGE`, `MODE`, `FEATURES` и другие). Для примеров из репозитория задайте `TARGET_VOLTAGE = 2200`.

Обученные модели сохраняются в `results_to_share/<дата>_<напряжение>_w30_1CNN/`.

## Применение модели

1. В `use_model.py` укажите `MODEL_DIR` — путь к папке обученной модели. Внутри неё должны быть каталоги `eventdetector_neg_training_results` и `eventdetector_pos_training_results`.
2. Для примеров из репозитория задайте `TARGET_VOLTAGE = 2200`.
3. Запустите:

```bash
python use_model.py
```

Результаты пишутся в `predictions_untouched/`.

## Библиотека eventdetector

Каталог `eventdetector/` — исходный код пакета [eventdetector-ts](https://github.com/m-azib/eventdetector_ts) (Menouar Azib, статья [arXiv:2310.16485](https://arxiv.org/abs/2310.16485)). Это сторонний код, а не код диссертации: скрипты только добавляют каталог в `sys.path` и импортируют библиотеку.

В репозитории лежит собственная копия библиотеки с исправленными ошибками и внесенными улучшениями: [eventdetector_2.0](https://github.com/reediculous/eventdetector_2.0).
